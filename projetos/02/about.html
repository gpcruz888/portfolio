Sobre o Prumo

Uma proposta de planejamento financeiro para quem toma decisões no dia a dia de uma pequena empresa.

Finanças para quem toca a operação.

O Prumo Financeiro é um projeto conceitual para pequenas empresas. O site apresenta os serviços pela pergunta que cada gestor precisa responder: quanto entra e sai, quais ofertas têm margem e como se preparar para o próximo mês.
